# worktree — 別の worktree に Claude を立てる

新しいブランチの worktree を作り、そこで Claude を 1 つ起動する。subagent と違い、相手は独立した
セッションになる。既定ではこちらの会話は引き継がれない。`--fork` を付けると、こちらの会話を
複製したセッションを起動する。

```bash
"$GOZD_CLI_PATH" worktree new --prompt-stdin <<'EOF'
<渡す指示文>
EOF
```

作成した worktree の絶対パスを stdout に 1 行返す。失敗は理由を stderr に出して非 0 で終わる。
オプション一覧は `"$GOZD_CLI_PATH" worktree --help`。

> [!IMPORTANT]
> 指示文は上の形で渡す。本文は複数行で、バッククォート・`$`・引用符・`--flag` を含むため、
> 引数に畳むと引用符の開閉を数え間違える。
>
> - delimiter は `'EOF'` と quote する。本文中の `$` とバッククォートを展開させないため
> - 終端の `EOF` は行頭に置く
> - `'"'"'` で引用符を継ぎ足す形にしない。この形にする必要が出た時点で畳み方が間違っている
> - 1 行で済む短い指示だけ `--prompt "<指示文>"` を使ってよい

## 会話を引き継がせる

ユーザーが「この会話を複製して」「ここまでの文脈ごと別の worktree で」のように、文脈を引き継いだ
切り出しを求めたら `--fork` を付ける。

```bash
"$GOZD_CLI_PATH" worktree new --fork --prompt-stdin <<'EOF'
<渡す指示文>
EOF
```

- 複製されるのは、このコマンドを実行した時点までの会話
- 作業場所が新しい worktree に変わったことは Claude Code が相手に伝える。指示文には書かなくてよい
- ユーザーがセッションを分けたいだけなら、指示文を付けずに `"$GOZD_CLI_PATH" worktree new --fork`
  だけを実行する。相手は入力を待つ

## 指示文

渡した指示文は起動時に送信され、相手はすぐ実行を始める。

- `--fork` 無しでは、指示文は単体で完結させる。こちらの会話の文脈は渡らない
- `--fork` 付きでは、相手は会話を知っているので、分担のうち相手が受け持つ部分だけを書けばよい
- 何をするか、どこを見るか、何をもって完了かを書く
- 実行は非同期に進む。相手の結果を待つ処理を後ろに繋がない

## 渡す範囲

ユーザーが名指しした作業だけを渡す。複数作るなら、何をいくつ渡すかを先に示して合意を得る。

渡した後は実装を先回りせず、worktree のパスと渡した内容を報告して終わる。
