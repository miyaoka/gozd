# github-item

GitHub の PR / issue を **画面に描くときの語彙**を持つモジュール。

## 責務

同じ意味を運ぶ表示が、それを描く画面ごとに別々の定義を持たないようにする。CI の総合結果を
表す点の色、レビュー結果のラベル、PR / issue の種別を表すアイコンとラベル、gh の失敗を説明
する文言、項目のリンクを OS のブラウザへ渡す起動条件——いずれも「どの画面から見ても同じで
あるべきもの」で、ここが唯一の定義を持つ。

## 利用側への要求

- 同じ語彙を利用側で再定義しない。増やすときもここに足す
- CI 未登録・レビュー設定無しはいずれも undefined に落ちる。その扱いは
  [docs/git.md](../../../../../docs/git.md) の「得られなかった要約は描かない」に従う

## 持たないもの

- 取得と状態。ここは描き方だけを持ち、GitHub API の呼び出しやキャッシュは持たない
- 特定の画面のレイアウト。行の組み方や並びは描く側の関心
- 相対日時の整形。GitHub 以外の一覧（Claude セッション等）でも同じ表示を使うため
  `shared/time` が持つ
